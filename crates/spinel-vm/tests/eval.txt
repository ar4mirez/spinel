# What Ruby answers, as measured from CRuby.
#
# Every `#=>` in this file was produced by running the snippet on the real Ruby
# named in CI and recording `.inspect`. `scripts/eval-oracle.rb` is what
# re-checks them and `tests/eval.rs` is what makes Spinel agree, so the file is
# falsifiable in both directions: Ruby can disagree with it, Spinel can disagree
# with it, and CI fails on either.
#
# It is a measurement rather than a transcription because several answers here
# are not what a reading of the code would suggest. `-7 / 2` is -4 and not -3;
# `-7 % 2` is 1 and not -1; `!0` is false because 0 is truthy; `1 && 2` is 2
# rather than true. Each of those is a place an interpreter written from
# intuition is quietly wrong.
#
# Format: one snippet per line, its result after `#=>`. Snippets must terminate
# and must not raise — Spinel's *refusals* (a division by zero, a loop that never
# ends) are Rust-side tests, because Ruby's answer there is a value this slice
# deliberately does not have. A bignum used to be on that list; #225 landed it,
# and the rows for it are below.

# #13 — constants, modules, class bodies, `self`, singleton classes, `defined?`.
#
# Constant lookup order is documented nowhere and reads wrong from `variable.c`,
# so every rule below is a measurement rather than a reading. The two that catch
# people: a lexically enclosing module beats an ancestor, and a qualified `A::X`
# does *not* fall back to `Object` — Ruby removed that in 2.5.
#
# Every case names its own classes. The oracle runs these against one shared
# top level where a constant outlives the line that set it, while Spinel gives
# each line a fresh heap; a case that reused a neighbour's name would compare
# two different programs.

# -- reading and writing ---------------------------------------------------
CW1 = 1; CW1  #=> 1
CW2 = 1; ::CW2  #=> 1
module CW3; end; CW3::B = 2; CW3::B  #=> 2
class CW4; end; CW4::D = 3; CW4::D  #=> 3
CW5 = 1; CW5 = 2; CW5  #=> 2
CW6 = (1 + 2); CW6  #=> 3
class CW7; end; CW7.class  #=> Class
module CW8; end; CW8.class  #=> Module

# -- lexical scope beats the ancestor chain --------------------------------
class LB1; K = "ancestor"; end; module LO1; K = "lexical"; class LI1 < LB1; def self.k; K; end; end; end; LO1::LI1.k  #=> "lexical"
class LB2; K = "ancestor"; end; module LO2; K = "lexical"; class LI2 < LB2; K = "own"; def self.k; K; end; end; end; LO2::LI2.k  #=> "own"
class LB3; K = "ancestor"; end; module LO3; class LI3 < LB3; def self.k; K; end; end; end; LO3::LI3.k  #=> "ancestor"
LT4 = "top"; module LM4; def self.t; LT4; end; end; LM4.t  #=> "top"
module LA5; X = 1; class LB5; def m; X; end; end; end; LA5::LB5.new.m  #=> 1
module LA6; X = 1; class LB6; def self.m; X; end; end; end; LA6::LB6.m  #=> 1
module LA7; X = 1; module LM7; class LC7; def m; X; end; end; end; end; LA7::LM7::LC7.new.m  #=> 1

# -- a block resolves constants where it was written ------------------------
# `yield` rather than `Array#map`: the point is where the block's constants
# resolve, and `map` is #15's.
class BC1; X = 7; def self.each; yield; end; def self.m; each { X }; end; end; BC1.m  #=> 7
module BA2; X = 1; class BB2; def each; yield; end; def m; each { X }; end; end; end; BA2::BB2.new.m  #=> 1

# -- qualified lookup -------------------------------------------------------
class QB1; I = "inherited"; end; class QS1 < QB1; end; QS1::I  #=> "inherited"
module QM2; N = 1; end; QM2::N  #=> 1
# `Object` alone is skipped by a qualified lookup, and only when it is not the
# receiver. `Kernel` and `BasicObject` are searched like any other ancestor —
# narrower than "no fallback", and the difference is a `NameError`.

# answer is cached, and a cache that outlived the definition would repeat it.
module Ex1; def w; "A"; end; end; o = Object.new; o.extend(Ex1); o.w  #=> "A"
module Ex2; def w; "A"; end; end; module Ex3; def w; "B"; end; end; o = Object.new; o.extend(Ex2, Ex3); o.w  #=> "A"
module Ex4; def w; 1; end; end; o = Object.new; before = o.respond_to?(:w); o.extend(Ex4); [before, o.respond_to?(:w)]  #=> [false, true]
module Ex5; extend self; def h; 1; end; end; Ex5.h  #=> 1
class Iv1; end; c = Iv1.new; before = c.respond_to?(:t); class Iv1; def t; 1; end; end; [before, c.respond_to?(:t)]  #=> [false, true]

# --------------------------------------- argument evaluation order (#160)
# Ruby expands a splat at the point it is *written*, before anything to its
# right is evaluated. This convention keeps the array on the stack and expands
# it at the call, so an argument to the right could change what the splat saw.
# Most rows below are cases where the two orders give different answers; the
# last few are the ones that must stay the same.
def ao(*a) = a; x = [1, 2]; ao(*x, x.pop)  #=> [1, 2, 2]
def ao(*a) = a; x = [1, 2]; ao(*x, x.push(9).size)  #=> [1, 2, 3]
def ao(*a) = a; x = [1, 2]; ao(*x, *x)  #=> [1, 2, 1, 2]
def ao(*a) = a; x = [1, 2]; ao(x.pop, *x)  #=> [2, 1]
def ao(*a) = a; x = [1, 2]; ao(*x)  #=> [1, 2]
def ao(*a) = a; x = [1, 2]; ao(*x, 3)  #=> [1, 2, 3]
def aob(*a, &b) = [a, b]; x = [1, nil]; aob(*x, &x.pop)  #=> [[1, nil], nil]
def aob(*a, &b) = [a, b]; x = [1, nil]; aob(*x, 2, &x.pop)  #=> [[1, nil, 2], nil]
def aob(*a, &b) = a; x = [1, 2]; aob(*x) { 3 }  #=> [1, 2]
# A splat of something that is not an Array is passed through unchanged, and
# capturing it must not change that.
def ao(*a) = a; x = 1; ao(*x, 2)  #=> [1, 2]
def ao(*a) = a; x = nil; ao(*x, 2)  #=> [2]

# ---------------------------------------------- a missing method raises (#170)
# A failed dispatch is an ordinary Ruby raise, so a `rescue` catches it. Before
# #170 it was a Rust-level error that unwound past every handler, and none of
# the rows below could be written at all.
#
# The message is not one wording: `nil`, `true`, `false`, a class, and a module
# each read differently from an ordinary instance. That is measured here rather
# than transcribed, because three of the five are text a spec asserts on and a
# reading of CRuby's `error.c` is exactly where the wrong one comes from.
#
# Anonymous receivers are absent on purpose: CRuby writes the object's address
# into the message, so no table can hold the answer.
begin; Object.new.nope; rescue NoMethodError => e; e.class; end  #=> NoMethodError
begin; Object.new.nope; rescue => e; e.class; end  #=> NoMethodError
begin; Object.new.nope; rescue NoMethodError => e; e.is_a?(NameError); end  #=> true
begin; Object.new.nope; rescue NoMethodError => e; e.is_a?(StandardError); end  #=> true
begin; Object.new.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for an instance of Object"
begin; 1.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for an instance of Integer"
begin; :s.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for an instance of Symbol"
begin; nil.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for nil"
begin; true.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for true"
begin; false.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for false"
begin; Object.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for class Object"
begin; Comparable.nope; rescue NoMethodError => e; e.message; end  #=> "undefined method 'nope' for module Comparable"
begin; Object.new.nope; rescue NoMethodError => e; e.name; end  #=> :nope
begin; Object.new.nope(1, 2); rescue NoMethodError => e; e.name; end  #=> :nope
o = Object.new; begin; o.nope; rescue NoMethodError => e; e.receiver.equal?(o); end  #=> true
begin; nil.nope; rescue NoMethodError => e; e.receiver; end  #=> nil
begin; 7.nope; rescue NoMethodError => e; e.receiver; end  #=> 7
begin; Object.nope; rescue NoMethodError => e; e.receiver.equal?(Object); end  #=> true
# The raise is a value like any other: it unwinds out of a method, and an
# `ensure` on the way still runs.
def m170; Object.new.nope; end; begin; m170; rescue NoMethodError => e; e.name; end  #=> :nope
r170 = []; begin; begin; Object.new.nope; ensure; r170.push(1); end; rescue NoMethodError; r170; end  #=> [1]
begin; Object.new.nope; rescue NoMethodError; "caught"; else; "no"; end  #=> "caught"
# `respond_to?` still answers without raising, which is what the guards in
# ruby/spec lean on.
Object.new.respond_to?(:nope)  #=> false

# --------------------------------------------------------- keyword rest (#193)
# Ruby 3 separated keywords from a positional Hash, and the corners are not what
# reading suggests: a braced Hash argument stays positional, a brace-less one is
# keywords, and `m(h)` passes the Hash positionally where Ruby 2 passed it as
# keywords. Every row below was measured on ruby 4.0.6.
#
# A row's value is never a Hash: `Hash#inspect` still writes `{:a => 1}` where
# ruby 4.0 writes `{a: 1}`, so such a row would measure that rather than the
# keywords. `.keys`, `.values` and `[]` say the same thing without it.
(def kr1(*a, **kw) = [a.size, kw.size]; kr1({"a" => 1}))  #=> [1, 0]
(def kr2(*a, **kw) = [a.size, kw.size]; kr2("a" => 1))  #=> [0, 1]
(def kr3(*a, **kw) = kw["a"]; kr3("a" => 1))  #=> 1
(def kr4(*a, **kw) = kw.keys; h = {a: 1}; kr4(**h))  #=> [:a]
(def kr5(*a, **kw) = [a.size, kw.size]; h = {a: 1}; kr5(h))  #=> [1, 0]
(def kr6(*a, **kw) = [a, kw.keys]; kr6(1, k: 2))  #=> [[1], [:k]]
# Order is the source's, and a duplicate key is the last one written.
(def kr7(**kw) = kw.keys; kr7(**{a: 1}, **{b: 2}))  #=> [:a, :b]
(def kr8(**kw) = kw.keys; kr8(k: 1, **{b: 2}))  #=> [:k, :b]
(def kr9(**kw) = kw.keys; kr9(**{b: 2}, k: 1))  #=> [:b, :k]
(def kra(**kw) = kw[:a]; kra(**{a: 1}, **{a: 2}))  #=> 2
(def krb(**kw) = kw.size; krb(**{}))  #=> 0
# A named keyword takes its own; `**rest` takes what is left.
(def krc(a:, b: 9, **rest) = [a, b, rest.keys]; krc(a: 1))  #=> [1, 9, []]
(def krd(a:, b: 9, **rest) = [a, b, rest.keys]; krd(a: 1, b: 2, c: 3))  #=> [1, 2, [:c]]
# An anonymous `**` collects without binding, which is what stops the keywords
# being unknown.
(def kre(**) = :anon; kre(x: 1))  #=> :anon
# `**nil` accepts none at all.
(def krf(**nil) = :none; krf)  #=> :none

# ------------------------------------------- regexp back-references (#197)
# `$~` is defined whether or not anything matched; every ref derived from it is
# nil until a match gives it a value, and nil again after one fails. Measured
# one fresh process per line, because `$~` outlives the snippet that set it and
# a shared process reports the first answer for every later one.
defined?($~)  #=> "global-variable"
defined?($&)  #=> nil
defined?($1)  #=> nil
defined?($+)  #=> nil
("ab" =~ /(a)(b)/; [$1, $2, $3])  #=> ["a", "b", nil]
("ab" =~ /(a)(b)/; [$&, $`, $'])  #=> ["ab", "", ""]
("xaby" =~ /ab/; [$&, $`, $'])  #=> ["ab", "x", "y"]
("ab" =~ /(a)(b)/; defined?($&))  #=> "global-variable"
("ab" =~ /(a)(b)/; defined?($1))  #=> "global-variable"
("ab" =~ /(a)(b)/; defined?($3))  #=> nil
# A group the pattern declares but the match did not reach has no value, so
# `defined?` is nil and `$+` skips it: the rule is participation, not arity.
("a" =~ /(a)(b)?/; [$2, $+, defined?($2)])  #=> [nil, "a", nil]
("ab" =~ /(a)(b)/; $+)  #=> "b"
# A failed match clears them all — the last *successful* match is not kept.
("a" =~ /a/; "z" =~ /q/; [$~, $&, defined?($&)])  #=> [nil, nil, nil]
# Assigning `$~` moves what every derived ref answers, which is why it is the
# frame's match and not a global-table entry.
(m = /(x)/.match("x"); "ab" =~ /(a)(b)/; $~ = m; [$1, $2, $&])  #=> ["x", nil, "x"]
("a" =~ /(a)/; $~ = nil; [$1, $&, defined?($1), defined?($~)])  #=> [nil, nil, nil, "global-variable"]

# --------------------------- index and attribute assignment (#191)
# The expression is the right-hand side, never what the setter returned. The
# class below returns `:nope` from both writers, which is how ruby/spec checks
# it and what a lowering that leaves the send's result would get wrong.
(class E1; def initialize; @h = {}; end; def [](k) = @h[k]; def []=(k, v); @h[k] = v; :nope; end; def b = @b; def b=(v); @b = v; :nope; end; end; e = E1.new; e[0] = 5)  #=> 5
(class E2; def initialize; @h = {}; end; def [](k) = @h[k]; def []=(k, v); @h[k] = v; :nope; end; end; e = E2.new; e[0] = 1; e[0] += 2)  #=> 3
(class E3; def b = @b; def b=(v); @b = v; :nope; end; end; e = E3.new; e.b = 5)  #=> 5
(class E4; def b = @b; def b=(v); @b = v; :nope; end; end; e = E4.new; e.b = 1; e.b += 2)  #=> 3
# `||=` reads, and writes only where the read was falsy — so a truthy one never
# reaches the setter at all.
(class E5; def initialize(o); @o = o; end; def b = (@o << :get; @b); def b=(v); @o << :set; @b = v; end; end; o = []; e = E5.new(o); e.b = 1; o.clear; v = (e.b ||= 9); [v, o])  #=> [1, [:get]]
(class E6; def initialize(o); @o = o; end; def b = (@o << :get; @b); def b=(v); @o << :set; @b = v; end; end; o = []; e = E6.new(o); v = (e.b ||= 9); [v, o])  #=> [9, [:get, :set]]
# The receiver and the index are evaluated once, however many sends the form
# makes: `a[i()] += 1` calls `i()` one time, not two.
(n = 0; i = -> { n += 1; 0 }; a = [1, 2, 3]; a[i.call] += 5; [n, a])  #=> [1, [6, 2, 3]]
(n = 0; i = -> { n += 1; 0 }; a = [nil]; a[i.call] ||= 7; [n, a])  #=> [1, [7]]
# A multiple assignment evaluates its targets' receivers and indices, left to
# right, *before* the right-hand side.
(class E7; def initialize(o); @o = o; @a = [0, 0]; end; def []=(i, v); @o << [:set, i, v]; @a[i] = v; end; end; o = []; r = E7.new(o); r[(o << :i1; 0)], r[(o << :i2; 1)] = (o << :rhs; 5), 6; o)  #=> [:i1, :i2, :rhs, [:set, 0, 5], [:set, 1, 6]]
(class E8; def initialize(o); @o = o; end; def b=(v); @o << [:set, v]; @b = v; end; end; o = []; e = E8.new(o); x, e.b = (o << :rhs; 1), 2; [x, o])  #=> [1, [:rhs, [:set, 2]]]
# A private setter is reachable through an explicit `self`, which is the one
# exception `self.attr = v` has always had.
(class E9; def go; self.foo ||= 6; end; def foo = @foo; def foo=(v); @foo = v; end; private :foo=; end; E9.new.go)  #=> 6

# ------------------------- a destructuring block parameter beside another (#209)
#
# `ParamSpec` carries a slot per required and post parameter rather than a

# ----------------------------------- `$!`, the exception being handled (#206)
#
# Not a frame's value and not an entry in the global table: one cell per heap,
# set where a handler takes an exception and restored on every path out of the
# clause. A method or block called from inside a `rescue` sees it, and nothing
# after the clause does — including after a `return` or a `break` out of one.
(raise("x") rescue $!.class)  #=> RuntimeError
begin; raise "y"; rescue; $!.message; end  #=> "y"
begin; raise "y"; rescue; $!.class; end  #=> RuntimeError
# Outside any handler.
$!.inspect  #=> "nil"
begin; raise "t"; rescue; end; $!.inspect  #=> "nil"
# A nested clause finishing restores the outer one, rather than leaving its
# own exception behind.
begin; raise "a"; rescue; (raise "b" rescue nil); $!.message; end  #=> "a"
begin; raise "c"; rescue => e206; [$!.equal?(e206), $!.message]; end  #=> [true, "c"]
begin; 1; rescue; 2; else; $!.inspect; end  #=> "nil"
begin; raise "d"; rescue; [1].map { $!.message }.first; end  #=> "d"
begin; begin; raise "p"; rescue; raise "q"; end; rescue; $!.message; end  #=> "q"
# A re-raise caught by an outer clause in the same frame still restores.
begin; begin; raise "o"; rescue; raise "i"; end; rescue; end; $!.inspect  #=> "nil"
def s206; $!.inspect; end; begin; raise "x"; rescue; s206; end  #=> "#<RuntimeError: x>"
# `return` and `break` out of a clause skip the compiler's restore, and the
# frame gives the cell back as it found it.
def r206; begin; raise "q"; rescue; return 1; end; end; r206; $!.inspect  #=> "nil"
[1].each { begin; raise "b"; rescue; break; end }; $!.inspect  #=> "nil"
def y206; begin; raise "z"; rescue; yield; end; end; y206 { $!.message }  #=> "z"
# `defined?($!)` is the constant answer, inside a clause and outside one.
defined?($!)  #=> "global-variable"
begin; raise "w"; rescue; defined?($!); end  #=> "global-variable"
# An `ensure` sees it while an exception is still propagating through it, and
# nil on every other path — including after a `rescue` already handled one.
begin; begin; raise "u"; ensure; $e206 = $!.message; end; rescue; $e206; end  #=> "u"
begin; begin; raise "v"; ensure; end; rescue; end; $!.inspect  #=> "nil"
begin; raise "h"; rescue; ensure; $f206 = $!.inspect; end; $f206  #=> "nil"

# ------------------- `return` in a singleton class body (#204)
#
# A `class << obj` body is transparent to `return`: it leaves the enclosing
# method, not the body. Measured every way in: written in the body, reached

# --- #231, symbol interpolation -------------------------------------------
#
# `:"a#{b}"` builds the name the way `"a#{b}"` does and interns the result at
# run time, because the iseq's symbol table is fixed when the iseq is compiled.
#
# `equal?` is the row that matters: an interpolated symbol must land in the same
# process-wide table a literal one does, or `:"a#{b}" == :ac` would be true
# while `equal?` was false and every method cache keyed on a symbol would be
# wrong. Redefining `String#to_sym` deliberately does not appear: it does not
# change what a dsym evaluates to, which is why the lowering is its own opcode
# rather than a send.
b231 = "c"; :"a#{b231}".to_s  #=> "ac"
b231 = "c"; :"a#{b231}".equal?(:ac)  #=> true
b231 = "c"; :"a#{b231}".class  #=> Symbol
:"a#{1 + 1}b".to_s  #=> "a2b"
:"#{nil}".size  #=> 0
:"#{:sym}".to_s  #=> "sym"
o231 = Object.new; def o231.to_s; "F"; end; :"a#{o231}".to_s  #=> "aF"
b231 = "c"; { :"a#{b231}" => 1 }[:ac]  #=> 1
b231 = "c"; :"a#{b231}" == :ac  #=> true
b231 = "ac"; :"#{b231}".equal?(:"a#{"c"}")  #=> true

# --- #224, safe navigation -------------------------------------------------
#
# `a&.b` is the send with a jump around it when the receiver is nil. Two rules
# are easy to get backwards, so both are measured rather than believed.
#
# Only `nil` short-circuits. `false&.to_s` is `"false"`, not `nil`, which is why
# the opcode tests for nil and not for truthiness.
#
# The short circuit reaches everything to the right of the receiver: arguments,
# block, and — in the assignment forms — the right-hand side. The `side224`
# rows are the ones that pin it, and they are the reason `a&.b += v` is a jump
# emitted before the read rather than a `nil` check on the result.
nil&.size  #=> nil
"ab"&.size  #=> 2
false&.to_s  #=> "false"
nil&.a&.b  #=> nil
[1, 2]&.map { |q| q * 2 }  #=> [2, 4]
nil&.map { |q| q }  #=> nil
$side224 = 0; nil&.foo($side224 += 1); $side224  #=> 0
$n224 = 0; def cnt224; $n224 += 1; "ab"; end; cnt224&.size; $n224  #=> 1
k224 = Class.new { attr_reader :m; def initialize; @m = 0; end; def m=(v); @m = v; 42; end }; o = k224.new; o&.m += 3; o.m  #=> 3
k224b = Class.new { attr_reader :m; def initialize; @m = 0; end; def m=(v); @m = v; 42; end }; o = k224b.new; (o&.m = 9)  #=> 9
o224 = nil; (o224&.m = 3)  #=> nil
$side224b = 0; o = nil; (o&.m = ($side224b += 1)); $side224b  #=> 0
$side224c = 0; h = nil; (h&.x += ($side224c += 1)); $side224c  #=> 0

# --- #221, argument forwarding ---------------------------------------------
#
# `...` is the anonymous `*`, `**` and `&` at once. Every row below was run
# against CRuby first, because two of the rules are ones a reasonable
# implementation gets wrong in the same direction.
#
# No empty keyword hash is manufactured. `f221d(9)` reaching `def g221d(x)`
# answers 9, not an ArgumentError about a stray `{}`, and `f221c(1, 2)` reaching
# `def e221c(*args)` answers `[1, 2]`.
#
# Forwarding works from inside a block, `r221h` and `r221i`, which is why the
# slot is searched outward instead of resolved at depth 0.
#
# `**` alone is the row that caught a silent wrong answer: it used to share an
# arm with `**nil` and quietly forwarded nothing.
def b221(x, k: 0); [x, k]; end; def a221(...); b221(...); end; a221(1, k: 2)  #=> [1, 2]
def b221b(x, k: 0); [x, k]; end; def a221b(...); b221b(...); end; a221b(1)  #=> [1, 0]
def t221(p1, p2, k: 0); [p1, p2, k]; end; def l221(x, ...); t221(x, ...); end; l221(1, 2, k: 3)  #=> [1, 2, 3]
def c221(&blk); blk.call(5); end; def d221(...); c221(...); end; d221 { |v| v * 2 }  #=> 10
def e221c(*args); args; end; def f221c(...); e221c(...); end; f221c(1, 2)  #=> [1, 2]
def g221d(x); x; end; def f221d(...); g221d(...); end; f221d(9)  #=> 9
def e221e(*a); a; end; def r221e(*); e221e(*); end; r221e(1, 2)  #=> [1, 2]
def k221(**kw); kw; end; def r221f(**); k221(**); end; r221f(a: 1)[:a]  #=> 1
def k221b(**kw); kw; end; def r221fb(**); k221b(**); end; r221fb(a: 1).size  #=> 1
def bc221(&z); z.call(7); end; def r221g(&); bc221(&); end; r221g { |v| v + 1 }  #=> 8
def e221h(*a, **k); [a, k]; end; def f221h(...); [1].map { e221h(...) }; end; f221h(1).first.first  #=> [1]
def e221hb(*a, **k); [a, k]; end; def f221hb(...); [1].map { e221hb(...) }; end; f221hb(1, k: 2).first.last[:k]  #=> 2
def e221i(*a); a; end; def g221i(*); [1].map { e221i(*) }; end; g221i(7, 8)  #=> [[7, 8]]
def e221j(*a, **k); [a, k]; end; e221j(1, **nil).first  #=> [1]
def e221jb(*a, **k); [a, k]; end; e221jb(1, **nil).last.size  #=> 0
n221 = nil; ({ **n221 }).size  #=> 0
n221b = { x: 1 }; ({ **n221b })[:x]  #=> 1

# --- #225, an integer wider than a fixnum ----------------------------------
#
# Ruby has one `Integer` and no visible boundary, so the promotion has to be
# invisible in both directions. `r225c` is the row that pins the second half:
# `(2**70) - (2**70)` is `0`, the same value the literal is, not a heap cell
# that merely prints as zero.
#
# `/` and `%` floor. `num-bigint` truncates the way Rust does, so the negative
# rows are the ones that would catch the correction going missing — `-4` and
# `1` for fixnums, and the same shape two powers of two apart.
#
# `false` for `2**70 == 2**70 + 1` is not the tautology it looks like: compared
# as `f64` both sides round to the same double and it would be true.
2**70  #=> 1180591620717411303424
(2**70).class  #=> Integer

(-(2**70)) % 7  #=> 5
(2**70).to_s  #=> "1180591620717411303424"

2**70 == 2**70 + 1  #=> false

# --- PRD 0034 validation: equality past 2^53 --------------------------------
#
# `2**70 == 2**70 + 1` is above, and was the half of this that #225 fixed. The
# other half is a *fixnum* pair: an `i64` past 2^53 also rounds when it is cast
# to `f64`, and `ruby_eq` used to compare every numeric pair as floats. So
# `2**54 == 2**54 + 1` answered true, and because `Hash` looks a key up with
# `==`, `{2**54 => 1}[2**54 + 1]` answered 1 — a wrong value, not a refusal,
# which is why no spec caught it: the examples that would are blocked on
# something else, and a pass count cannot see a method that answers wrongly.
#
# The mixed arm is exact for the same reason: a float equals an integer only
# when it is finite, integral, and names that integer.
2**54 == 2**54 + 1  #=> false
1152921504606846976 == 1152921504606846977  #=> false
2**54 != 2**54 + 1  #=> true
2**54 < 2**54 + 1  #=> true
{ 2**54 => 1 }[2**54 + 1]  #=> nil
{ 2**54 => 1 }[2**54]  #=> 1
[2**54].include?(2**54 + 1)  #=> false
1 == 1.0  #=> true
1 == 1.5  #=> false
2**54 == (2**54).to_f  #=> true
2**54 + 1 == (2**54).to_f  #=> false
(2**54).to_f == 2**54 + 1  #=> false

# --- PRD 0034 validation: Symbol#inspect quoting ----------------------------
#
# `#231` made a symbol whose name is not an identifier easy to build, and
# `inspect` was `":" + to_s`, so `:"#{nil}"` printed as a lone colon. Three
# shapes print bare — an operator, an identifier with an optional `?`/`!`/`=`,
# and an ivar/cvar/gvar — and the sigil forms take no suffix, which is the pair
# `:a?` and `:"@a?"` below.
:ab.inspect  #=> ":ab"
:"a b".inspect  #=> ":\"a b\""
:"".inspect  #=> ":\"\""
:"a-b".inspect  #=> ":\"a-b\""
:"1x".inspect  #=> ":\"1x\""
:a?.inspect  #=> ":a?"
:"a=".inspect  #=> ":a="
:"@a?".inspect  #=> ":\"@a?\""
:@x.inspect  #=> ":@x"
:$1.inspect  #=> ":$1"
:"@1".inspect  #=> ":\"@1\""
:+.inspect  #=> ":+"
:[].inspect  #=> ":[]"
:<=>.inspect  #=> ":<=>"
bq34 = "c"; :"a#{bq34}".inspect  #=> ":ac"
:"#{nil}".inspect  #=> ":\"\""
